# منصة محسوب المركزية لإدارة التراخيص والاشتراكات (Mahsoob SaaS Master Control Plane)
### شركة المدار للحلول البرمجية — Almadar Tech Solutions | البصرة، العراق

منصة الويب المركزية السيادية لشركة «المدار» لإدارة وتوزيع تطبيق «محسوب» كخدمة سحابية مدفوعة (**B2B SaaS**) لقطاع المطاعم والمطابخ والمشاريع التجارية في العراق.

---

## 🌟 الميزات الجوهرية للمنصة (Core Features)

1. **إدارة المطاعم المشتركة (Tenants Management):**
   - تسجيل أي مطعم جديد، تحديد محافظته (البصرة، بغداد، أربيل...)، ورقم هاتف المالك.
   - توليد كود ترخيص مشفر فريد لكل مطعم (مثال: `MAHSOOB-BSR-9081-PRO`).
   - توليد رمز QR صالح للمسح المباشر بكاميرا تطبيق الجوال للربط السريع.

2. **باقة موحدة وشاملة لكافة ميزات التطبيق (All-in-One Suite):**
   - التطبيق يأتي مفتوحاً بالكامل افتراضياً لجميع العملاء (كاشير، مشتريات، مشرف، مخازن، شيف، مالك، ذكاء اصطناعي، طبخ مركزي، تقارير PDF).
   - مصفوفة مفاتيح تحكم مرنة (Feature Toggles) تمكن شركة المدار من تخصيص أو قفل أي ميزة محددة عن بُعد للمطعم حسب الحاجة.

3. **إدارة الفروع والموظفين ومصفوفة الـ PINs (Staff & Branches RBAC):**
   - إضافة فروع لكل مطعم وتحديد الفروع المسموح بها.
   - تسجيل الموظفين وتعيين أدوارهم في التطبيق (كاشير صالة، كاشير سفري، مشرف شفت، أمين مخزن، شيف، مشتريات، مالك).
   - تحديد وتعديل رموز الدخول السريع (PIN Codes) فورياً من المنصة؛ وبمجرد تعديل الـ PIN هنا يتحدث فوراً في التطبيق.

4. **مركز الإيقاف الفوري (Remote Kill-Switch):**
   - تجميد وصول أي مطعم عن بُعد بنقرة واحدة (عند تأخر سداد الاشتراك الشهري أو السنوي).
   - تخصيص نص رسالة القفل التي تظهر لجميع عمال المطعم عند فتح التطبيق (مثال: *"انتهت فترة اشتراكك في نظام محسوب. يرجى مراجعة شركة المدار: +9647878777217"*).

5. **الاشتراكات والفوترة لشركة المدار (SaaS Billing & Invoices):**
   - تتبع مواعيد انتهاء عقود المطاعم (شهري / سنوي).
   - تسجيل الدفعات المستلمة بالدينار العراقي (`IQD د.ع`).
   - طباعة وتوليد وصولات استلام رسمية من شركة المدار.

6. **سجل الرقابة والأمان (System Audit Trail):**
   - توثيق زمني دقيق لكل حركة (إنشاء ترخيص، تعديل ميزات، إيقاف قسري، تغيير PIN).

7. **احترام الخصوصية التامة لبيانات المطاعم (Zero-Knowledge Privacy):**
   - المنصة لا تتدخل في فواتير مبيعات المطاعم اليومية أو مخزونهم الداخلي السري، وتركز حصرياً على حوكمة التراخيص وحسابات الموظفين.

## 🎨 الهوية البصرية ونظام التصميم

- **الخلفيات:** الكانفاس الطبيعي الدافئ (`#F7F6F2`).
- **الأخضر الزمردي:** `#15803D` (اللون السيادي للأزرار والإجراءات المعتمدة).
- **الأحمر القرمزي:** `#8B1E1E` (للإيقاف الفوري والتنبيهات).
- **الأزرق الداكن للشركة:** `#101828` و `#345875` (هوية شركة المدار).
- **الخطوط:** `Changa` للأرقام والواجهات التفاعلية، و `IBM Plex Sans Arabic` للنصوص التحريرية.

## 🚀 طريقة التشغيل الفوري

المنصة مصممة بتقنيات الويب الحديثة خفيفة الوزن وبدون أي اعتمادات خارجية معقدة:
1. انقر نقراً مزدوجاً على ملف `index.html` لفتحه في أي متصفح (Chrome, Edge, Safari, Firefox).
2. أو شغل خادم محلي خفيف في المجلد:
```bash
python -m http.server 8080
# ثم افتح المتصفح على: http://localhost:8080
```

## 🔌 خطة الربط اللاحق بقاعدة البيانات (Future Backend & Database Sync)

تم بناء طبقة البيانات `assets/js/store.js` بطريقة تجريدية نموذجية (Clean Store Abstraction):
- حالياً تحفظ البيانات محلياً في المتصفح `localStorage` مع دعم التصدير.
- للربط مع قاعدة بيانات سحابية (مثل PostgreSQL / Supabase / Firebase / REST API مخصص):
  يكفي استبدال دوال الحفظ في `store.js` بطلبات `fetch()` موجهة للـ Backend API، وتمرير كود الترخيص `licenseKey` كنقطة وصل مع تطبيق فلاتر الجوال `mahsoob_mobile`.
